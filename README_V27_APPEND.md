## V27 — Fase 15: Workspace Unificado do Projeto

A página Projetos passa a abrir cada projeto diretamente em um workspace
único, com navegação interna para briefing, recomendações, estratégia,
cenografia, ativações, brindes e press kits, orçamento, fornecedores,
apresentações, feedbacks, resultados e documentos.

A tela intermediária “Áreas do projeto” foi removida do fluxo.

A Visão geral permite anexar diretamente:

- briefing original;
- planilha de custos;
- apresentação final;
- feedbacks e aprovações;
- relatório de encerramento;
- relatório pós-execução.

Foi adicionada a tabela `project_files` e o bucket privado
`nave-project-files`.

A Memória permanece como camada técnica de inteligência do projeto e não
como destino obrigatório de navegação.
